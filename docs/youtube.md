# YouTube downloads

The worker accepts individual watch, Shorts and youtu.be URLs. It prefers a compatible native MP4, uses the user's quality and HDR preferences, and can combine separate audio and video streams with FFmpeg. Install Deno for yt-dlp. YouTube login is optional. Import Netscape cookies into the YouTube pool in the console.

With segmented streams, yt-dlp can skip an unavailable fragment and still return a playable but incomplete file. A successful transfer alone does not establish that the upstream stream contained every segment.
